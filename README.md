# How to contribute

Now this is a website about me so I don't understand why you would want to contribute but heres the way to do it anyway. However, If you want to use it as a template for your very own site, You may

1. Clone this repository
2. All the information (paragraphs, titles, headings etc) is stored in the main.html file, You may make edits there to change this information
3. All the styling needs (containers, boxes, background, how the mouse glow looks etc) is stored in the style.css file, You may make edits to change the style of the website
4. To add any Javascript traits please look at the <script> section near the end of main.html, You may add them there
5. To test the website you can try the 'Live Preview' plugin in VSCode to launch a local instance of the site before submitting any changes
6. after making any changes, Go ahead and submit a pull request (no idea why you would do this, I am probably not going to add it)
7. If you want to use this as a template then you can use your own cloud service provider (Vercel or GitHub pages to host your site)
